# 第3回 解答

## 演習

- 第1回（素のLLM）とエージェントの回答の違い：

  第1回では、Geminiに直接質問し、モデル内部の知識に基づく回答を取得した。第3回では、AIエージェントが`search_glossary`を使用して講座の用語集を検索し、取得した情報に基づいて回答した。

  「LoRAとQLoRAの違いは？」という質問では、両者の定義を検索したうえで違いを説明し、関係する講義回として「第2回」を示した。素のLLMとは異なり、外部資料を参照する過程を確認できる点が特徴的だった。

- `--trace`で見えたツール呼び出し（ツール名と引数）：

  ```text
  [tool call] search_glossary({'query': 'LoRA'})
  [tool call] search_glossary({'query': 'QLoRA'})
  ```

  用語を1つずつ検索し、それぞれの定義を取得したことを確認した。

- 1つの質問でのLLM呼び出し回数（`requests`）：

  ```text
  requests=2, tool_calls=2
  ```

  LLMを2回呼び出し、検索ツールを2回使用した。

- 追加したツールと、docstringに書いた説明：

  演習では新規ツールの追加は実施していない。既存の`search_glossary`の動作を確認し、基礎課題ではそのdocstringを変更して比較実験を行った。

## 宿題

- 取り組んだレベル：**基礎**

- やったこと：

  AIエージェントへの指示文がツールの使用方法に与える影響を検証するため、以下の3条件で比較した。

  **条件①：元の設定**

  `INSTRUCTIONS`に「用語や講座に固有のことを答える前に、必ずsearch_glossaryで用語集を確認する」という指示がある状態で実行した。

  **条件②：INSTRUCTIONSの変更**

  `app/agent.py`から上記の指示を1行削除し、同じ質問で検索ツールの呼び出し方と回答を比較した。

  **条件③：docstringの変更**

  `INSTRUCTIONS`を元に戻したうえで、`app/tools.py`の`search_glossary`の説明文を変更した。

  変更前：
  `queryには調べたい用語を1つだけ入れる`

  変更後：
  `複数の用語を比較する場合は、queryに用語をまとめて指定する`

  各条件で「LoRAとQLoRAの違いは？」という同一の質問を`--trace`付きで実行した。

- 結果：

  | 評価項目 | 元の設定 | INSTRUCTIONS変更 | docstring変更 |
  |---|---:|---:|---:|
  | 検索ツール呼び出し回数 | 2回 | 2回 | 1回 |
  | LLM呼び出し回数 | 2回 | 2回 | 2回 |
  | 入力トークン数 | 1,196 | 1,148 | 899 |
  | 出力トークン数 | 188 | 205 | 217 |
  | 検索方法 | 個別検索 | 個別検索 | まとめて検索 |

  **条件②：INSTRUCTIONS変更後**

  必須検索の指示を削除しても、`search_glossary`が2回呼び出され、LoRAとQLoRAをそれぞれ検索した。回答内容にも大きな違いは見られなかった。

  **条件③：docstring変更後**

  ツールの説明文を変更したところ、次のように2つの用語をまとめて検索する動作に変化した。

  ```text
  [tool call] search_glossary({'query': 'LoRA QLoRA'})
  [usage] RunUsage(... requests=2, tool_calls=1)
  ```

  検索ツール呼び出し回数は2回から1回に減少し、入力トークン数も1,196から899に減少した。

  さらに、`search_glossary('LoRA QLoRA')`を直接実行し、1回の検索でLoRAとQLoRAの両方の定義を取得できることを確認した。

  **追加の動作確認**

  指示変更後の状態で異なる種類の質問も実行した。

  | 質問 | 使用ツール | ツール呼び出し回数 |
  |---|---|---:|
  | RAGとは何ですか？ | search_glossary | 3回 |
  | 第2回の講義では何を学びましたか？ | get_lecture_summary | 1回 |
  | 最終課題の締切日時を教えてください | search_glossary | 1回 |

  RAGについての質問では、検索結果が不十分だったため、英語の正式名称や日本語訳に検索語を変更し、再検索する動作が見られた。

  一方、講義内容についての質問では`get_lecture_summary`が選択された。最終課題の締切日時については、用語集に根拠がないことを伝え、推測による断定を避けた。

  最後に`uv run pytest -q`を実行し、**15件すべてのテストが成功**した。

- 気づき・疑問：

  今回の実験では、エージェント全体への指示である`INSTRUCTIONS`を変更しても、検索方法は変わらなかった。一方、個別ツールのdocstringを変更したところ、ツールへの引数が変わり、検索ツール呼び出し回数が減少した。

  このことから、AIエージェントの動作は全体の指示だけでなく、個々のツールの説明文にも影響されることがわかった。

  また、検索ツールへの入力を工夫することで、必要な情報を維持したままツール呼び出し回数を減らせる可能性が示された。ただし、今回の比較は各条件1回の実行であり、LLMの呼び出し回数は変わらなかったため、応答速度やコストの改善については追加の検証が必要である。

  さらに、RAGについての質問では、AIが検索結果に応じて検索語を変更する動作が確認できた。この結果から、AIエージェントは単にツールを呼び出すだけでなく、取得した情報に応じて次の行動を選択できることを理解した。

  今後は、同じ質問を複数回実行し、docstringの変更によるツール選択の再現性や、検索精度・応答時間への影響を定量的に評価したい。
